## XNA Color 颜色预览与选择器

### 功能说明

当 XML 属性的类型为 `Microsoft.Xna.Framework.Color` 时，编辑器会在属性值前面显示可点击的颜色图标。包括普通元素和逐层嵌套的 `M.*` 成员元素中的 Color 属性。

### 支持的颜色格式

1. **十六进制 RGB**: `#RRGGBB`
   - 示例: `#0099ff` (蓝色)
   
2. **十六进制 RGBA**: `#RRGGBBAA`
   - 示例: `#0099ff99` (半透明蓝色)
   
3. **RGB 函数**: `rgb(r, g, b)`
   - 示例: `rgb(255, 128, 0)` (橙色)
   - 值范围: 0-255
   
4. **RGBA 函数**: `rgba(r, g, b, a)`
   - 示例: `rgba(255, 255, 255, 0.5)` (半透明白色)
   - RGB 范围: 0-255
   - Alpha 范围: 0.0-1.0

### 交互功能

- **颜色预览**: 16x16px 颜色块，自动占用空间
- **点击选择**: 点击颜色块打开 Windows 标准颜色选择器
- **自动更新**: 选择新颜色后自动替换属性值为 `#RRGGBB` 或 `#RRGGBBAA` 格式
- **Alpha 保持**: 选择器不支持 Alpha，保持原有透明度值

### 示例

```xml
<Button BackgroundColor="#ff0000" />              <!-- 点击红色块选择新颜色 -->
<Panel BorderColor="#00ff0080" />                 <!-- 点击半透明绿色块 -->
<Text ForegroundColor="rgb(128, 128, 128)" />     <!-- 点击灰色块 -->
<View TintColor="rgba(0, 0, 255, 0.7)" />        <!-- 点击蓝色块 -->
```

### 实现细节

- **颜色块**: 16x16px，圆角 2px，灰色边框
- **占用空间**: 使用 IntraTextAdornmentTag，文本自动向右移动
- **工具提示**: 显示 RGBA 值和"点击选择颜色"提示
- **性能**: 仅对可见文本行渲染
- **响应式**: 文本编辑或元数据变化时自动刷新
